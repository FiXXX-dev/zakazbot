Импорт товаров

Файл .csv или .xlsx с колонками в первой строке: Наименование, Единица, Цена. Обязательна только колонка «Наименование». Сохраняется в таблицу products. Для CSV используйте кодировку UTF-8.

Импорт клиентов

Файл .csv или .xlsx с колонками в первой строке: Имя, Телефон. Обязательна только колонка «Имя». Сохраняется в таблицу clients; клиенты с уже существующим именем пропускаются. Для CSV используйте кодировку UTF-8.
